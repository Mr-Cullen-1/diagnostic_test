# Junior — диагностика по математике

Сайт помогает подобрать уровень математики для учеников 1–11 классов. Интерфейс доступен на русском и узбекском языках.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Проверка production-сборки:

```bash
npm run build
```

## Развёртывание на Vercel

1. Загрузите этот проект в GitHub, GitLab или Bitbucket.
2. В Vercel выберите **Add New → Project** и импортируйте репозиторий.
3. Vercel определит Next.js автоматически. Не меняйте команду сборки: используется `npm run build`.
4. Убедитесь, что в настройках проекта выбрана версия Node.js 22 или новее, затем нажмите **Deploy**.

Файл `.vercelignore` не даёт загрузить остатки исходного Cloudflare/Vinext-шаблона. Сам диагностический сайт не использует сервер, базу данных или переменные окружения.
